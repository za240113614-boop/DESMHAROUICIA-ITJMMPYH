# DESMHAROUICIA-ITJMMPYH

Ejemplos de mejora del habla en ruido
Material complementario de la tesis de maestría de Alan Omar Vega Cortés, Tecnológico Mario Molina (TecMM).

Este repositorio permite escuchar cómo cambia un fragmento de habla al aplicar el sistema de reducción de ruido desarrollado en la tesis. Las muestras se seleccionaron con fines ilustrativos. Los estímulos de la prueba de escucha se documentan en el Anexo A de la tesis.
Cómo escuchar los ejemplos
Cada ejemplo reúne tres versiones del mismo fragmento. Reprodúcelas en el orden indicado y mantén el mismo volumen del reproductor durante la comparación.
1. Voz limpia. Señal de referencia antes de añadir el ruido.
2. Mezcla ruidosa. El mismo fragmento con ruido añadido. Es la entrada al sistema.
3. Audio procesado. Salida del sistema al aplicar la reducción de ruido a esa mezcla.
Archivos y condiciones
Cada grupo de archivos conserva el mismo número de ejemplo. La relación señal-ruido (SNR) se refiere a la mezcla de entrada y se expresa en decibeles (dB).
